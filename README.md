📌 Finalidade do App

O MauiAppMinhasCompras é um aplicativo em desenvolvimento feito em .NET MAUI para gerenciar listas de compras de forma prática e organizada.
A proposta é permitir que o usuário possa:

📝 Cadastrar produtos com descrição, quantidade e preço.

✏️ Editar produtos cadastrados.

🗑 Excluir itens da lista.

🔍 Pesquisar produtos pelo nome.

📄 Listar todos os produtos salvos.

💾 O armazenamento será feito localmente usando SQLite, permitindo o uso do app mesmo sem conexão com a internet.

⚠️ Status do projeto: Em andamento — funcionalidades estão sendo implementadas e testadas.
